# Third-party references

This project is an original implementation informed by public documentation
and the product ideas of the following projects:

- `fuyi-git/token-dashboard` — visual and analytical inspiration. The
  repository did not contain a license when reviewed, so no source code was
  copied into this project.
- `xiufengsun/TokenTracker` — MIT-licensed local-first token accounting and
  Codex adapter concepts.
- `nateherkai/token-dashboard` — MIT-licensed SQLite, local HTTP server, and
  server-sent-events architecture concepts.
